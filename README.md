# JavaScript Logical Problems

This repository contains my JavaScript practice programs as I build my programming skills.

## Topics Covered

- Loops (`for` loops)
- Even and odd numbers
- Conditional statements (`if-else`)
- Number patterns and multiples
- String manipulation
- Arrays and array operations
- Functions and return values
- Sum, largest and smallest numbers
- Counting vowels, consonants, and characters
- DOM manipulation

## Technologies Used

- HTML5
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open an HTML file in VS Code.
3. Uncomment the program you want to practise, if it is commented out.
4. Open the HTML file in a browser.
5. Check the output in the browser console using `F12`.

## Purpose

This repository documents my JavaScript learning journey through hands-on coding exercises and logical problem-solving practice.

I will continue adding more practice programs as I improve my skills.
